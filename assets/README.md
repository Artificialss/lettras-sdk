# Lettras brand assets

Logos, icons and social images of [Lettras](https://lettras.org), for linking to or writing about the SDK, the npm package,
the Kotlin library and the MCP server (directory listings, articles, talks).

The mark is the word's own "tt" inside a mustard highlighter pill. Colors: mustard `#E1AD01`, ink `#000000`, paper `#FFF7EA`.
The logo uses Fredoka Bold ([SIL Open Font License](FONT-LICENSE-OFL.txt)); every file here is already outlined, so no font is needed.

| Folder | Files |
| --- | --- |
| `svg/` | `lettras-logo` (color), `-reversed` (for dark backgrounds), `-black`, `-white`; `lettras-mark*` (the pill alone); `lettras-icon` (app-icon tile); `lettras-banner-*` |
| `png/` | Logo 1200 and 2400 px wide, mark 512, icon 512, light banner 1600 |
| `social/` | Open Graph images 1200×630, English and Spanish (PNG + SVG) |
| `favicon.ico` | 16, 32 and 48 px |

**Do:** keep clear space of half the pill height around the logo; use at least 96 px wide on screen; use the black or white
version on photos or on mustard.

**Don't:** recolor the pill, change the letters, stretch, rotate, outline, or add shadows or gradients.

The brand files are not part of the MIT-licensed code. Use them to refer to Lettras; for anything else, ask via
[lettras.org](https://lettras.org).
